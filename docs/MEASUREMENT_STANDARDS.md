# 採寸標準項目定義

Sasage AI が出力する採寸項目を、既存の古着ささげ代行サービス（フクダス等）や
主要古着ECサイト（メルカリ、RAGTAG、2nd STREET 等）の表記に合わせて標準化した。
実装は `backend/app/services/measurement_standards.py` を正とし、本ドキュメントは
その内容を人間向けに解説するもの。コードとドキュメントに差分が出た場合はコードを正とする。

## 設計方針

- 出品者が実際に見て確認できる**採寸方法の定義**を明文化する（測る位置・向き）
- Phase 1 のヒューリスティック（マスク形状比率）で**推定できる項目**と
  **推定できない項目**を明確に分け、非対応の項目は `value_cm=null` +
  `method="not_supported_phase1"` として出力に含める。項目が黙って欠落すると
  受け取った出品者が「未計測」なのか「不要な項目」なのか判別できないため。
- `required` フラグは「出品時に購入者が最低限知りたい情報か」の目安。必須項目が
  Phase1で非対応の場合（ボトムスの股上・股下など）は Phase 2 で優先的に対応する。

## トップス / アウター / ワンピース

| 項目 | 定義（測り方） | 必須 | Phase1対応 |
|---|---|---|---|
| 着丈 | 肩の縫い目（衿ぐり後中心）から裾までの長さ | ○ | ○（基準実測値として利用） |
| 身幅 | 脇下から脇下までの水平幅 | ○ | ○ |
| 肩幅 | 肩の縫い目から縫い目までの直線距離 | ○ | ○ |
| 袖丈 | 肩の縫い目から袖口までの長さ | ○ | ○ |
| 裄丈 | 背中心から肩を通り袖口までの長さ（肩幅/2 + 袖丈で近似） | - | ○（近似式による導出値） |
| 袖口幅 | 袖口の開口部の幅 | - | ✕（Phase2でキーポイント検出が必要） |
| 襟ぐり幅 | 衿ぐり（首まわり開口部）の幅 | - | ✕（Phase2でキーポイント検出が必要） |

## ボトムス

| 項目 | 定義（測り方） | 必須 | Phase1対応 |
|---|---|---|---|
| 総丈 | ウエスト上端から裾までの長さ | ○ | ○ |
| ウエスト幅 | ウエスト部分を平置きで測った幅（実周囲は概ねこの2倍） | ○ | ○ |
| 股上 | ウエスト上端から股（クロッチポイント）までの長さ | ○ | ✕（クロッチポイント検出が必要） |
| 股下 | 股（クロッチポイント）から裾までの長さ | ○ | ✕（クロッチポイント検出が必要） |
| わたり幅 | 股下直下（もも付け根）の水平幅 | - | ✕（クロッチポイント検出が必要） |
| 裾幅 | 裾の開口部の水平幅 | - | ○ |

股上・股下・わたり幅は、平置きで前後どちらか一方の脚が重なって撮影されるため
「股の分岐点（クロッチポイント）」がマスクの外形だけでは判別できず、Phase1の
行幅プロファイル方式では非対応としている（詳細は `docs/PHASE2_MEASUREMENT_PLAN.md`）。

```json
    {"label": "肩幅", "value_cm": 71.8, "confidence": 0.55, "method": "heuristic_mask_ratio"},
    {"label": "身幅", "value_cm": 56.3, "confidence": 0.6, "method": "heuristic_mask_ratio"},
    {"label": "袖丈", "value_cm": 8.5, "confidence": 0.4, "method": "heuristic_mask_ratio"},
    {"label": "裄丈", "value_cm": 44.4, "confidence": 0.35, "method": "derived_formula"},
    {"label": "袖口幅", "value_cm": null, "confidence": 0.0, "method": "not_supported_phase1"},
    {"label": "襟ぐり幅", "value_cm": null, "confidence": 0.0, "method": "not_supported_phase1"}
  ]
}
```
